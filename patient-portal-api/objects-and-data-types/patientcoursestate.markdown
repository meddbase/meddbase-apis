# PatientCourseState

The status of a patient course. In JSON it is the name of the value, as a string.

## Values

| Value | Description |
|:------|:------------|
| Active | The patient can use the course. |
| Completed | The course is completed. |
| Refunded | The course is refunded. |
| Expired | The course is expired. |
