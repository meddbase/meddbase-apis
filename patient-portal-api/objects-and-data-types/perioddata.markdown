# PeriodData

A length of time in years, months and days. It is used for the expiry of a course and for the minimum interval of an allowance.

## Properties

| Parameter | Type   | Description                                                 |
|:----------|:-------|:------------------------------------------------------------|
| Years | int | The number of years. |
| Months | int | The number of months. |
| Days | int | The number of days. |

## JSON Example

```json
{
    "Years": 1,
    "Months": 0,
    "Days": 0
}
```
