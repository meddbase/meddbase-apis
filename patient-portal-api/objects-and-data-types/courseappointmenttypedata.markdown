# CourseAppointmentTypeData

The appointment type that can be used to book a service of a patient course. It is used in [CreditServiceData](../objects-and-data-types/creditservicedata).

## Properties

| Parameter | Type   | Description                                                 |
|:----------|:-------|:------------------------------------------------------------|
| Key | string | The key of the appointment type. |
| Name | string | The name of the appointment type. |

## JSON Example

```json
{
    "Key": "PHYS",
    "Name": "Physiotherapy session"
}
```
