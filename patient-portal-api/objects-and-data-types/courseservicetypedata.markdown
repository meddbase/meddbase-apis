# CourseServiceTypeData

The type of a service that a course covers. It is used in [CreditServiceData](../objects-and-data-types/creditservicedata).

## Properties

| Parameter | Type   | Description                                                 |
|:----------|:-------|:------------------------------------------------------------|
| Code | string | Code of the service type. |
| Name | string | Name of the service type. |

## JSON Example

```json
{
    "Code": "A",
    "Name": "Appointment"
}
```
